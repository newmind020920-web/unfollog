# 언팔로그 브랜드 자산

인스타그램·스레드 계정에 쓸 로고와 프로필 문구입니다.

## 파일

| 파일 | 쓰는 곳 |
| --- | --- |
| `unfollog-profile.png` | 프로필 사진 (1080×1080). 인스타·스레드에 그대로 올리면 됩니다. |
| `unfollog-mark.svg` | 같은 마크의 벡터. 크게 뽑거나 색을 바꿀 때 씁니다. |

마크는 **끊긴 고리** — 이어져 있던 팔로우가 한 곳 끊어진 모양입니다.
색은 사이트와 같은 인스타그램 계열 그라데이션(`#f7963c → #d42e86 → #7b3fe4`)입니다.

프로필 사진은 동그랗게 잘리므로 배경을 원으로 깔았습니다. 32px(피드)까지
줄여서 고리의 틈이 보이는지 확인했습니다.

**흰 배경 버전은 만들지 않았습니다.** 밝은 화면에서 32px이 되면 원이 사라지고
작은 고리만 떠서 피드에서 못 알아봅니다.

## 프로필 문구

### 이름 (검색에 걸리는 칸, 30자)

```
언팔로그 · 인스타 언팔 확인
```

이름 칸은 검색 대상입니다. "언팔"을 넣어 두면 검색으로 들어옵니다.

### 사용자 이름

1순위 `unfollog` · 다음 `unfollog.kr` · `unfollog.app`

사용 가능한지는 직접 만들어 보셔야 압니다. 여기서는 확인할 방법이 없습니다.

인스타그램 계정을 만들면 스레드는 **같은 아이디를 그대로 씁니다.** 따로
만들지 않아도 됩니다.

### 소개 (150자)

```
누가 나를 언팔했는지 알려드려요

로그인 안 해요 · 인스타 공식 파일만 써요
팔로워 목록은 내 폰 밖으로 안 나가요

↓ 무료로 확인
```

로그인을 요구하지 않는다는 점을 위로 올렸습니다. 이런 서비스는 대부분
비밀번호를 받아서, 사람들이 가장 먼저 의심하는 지점입니다.
